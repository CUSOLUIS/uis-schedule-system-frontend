# Carpeta de Imágenes

Esta carpeta contiene todas las imágenes utilizadas en el proyecto UIS Schedule System.

## Logo UIS


## Estructura recomendada

```
src/assets/images/
├── logoUIS.png          # Logo principal de la UIS
├── favicon.ico          # Icono del navegador (opcional)
└── README.md            # Este archivo
```

## Uso en el código

El logo se referencia en el HTML como:
```html
<img src="assets/images/logoUIS.png" alt="Logo UIS" class="uis-logo">
```

Y se estiliza con CSS en la clase `.uis-logo`.
